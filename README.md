# Flamingo Events & Rentals Abuja

A responsive, rounded-corner website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `styles.css` — layout, colours and responsive styling
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in your browser.

## Deploy on GitHub + Vercel
1. Extract the ZIP file.
2. Create a new repository on GitHub.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root (not inside another nested folder).
4. In Vercel, choose **Add New → Project**, import that GitHub repository, and deploy.
5. For this plain HTML website, no build command is required. If Vercel asks for a framework, select **Other** and leave the build command empty.
6. After deployment, open the generated Vercel URL and test the phone number, WhatsApp link and navigation.

## Before publishing
- Confirm the address, phone number, opening hours and service list with the client.
